# Interactive Narrative Game

## Overview

This team project was created through Duke's Arts+ program using Ren'Py.
The game follows a struggling game developer and allows players to influence
the story through interactive choices.

## My contributions

- Programmed branching dialogue and player choices
- Wrote and edited narrative content
- Designed characters
- Created visual assets and graphics
- Participated in playtesting and iteration

## Technologies

- Ren'Py
- Python
- Digital illustration
- Narrative design
- Game development
